# Создание SQL-запросов для анализа маркетплейса

YouSell - маркетплейс, который доставляет товары для дома, красоты, спорта по России. 
В файле "Анализ маркетплейса в SQL.txt" представлены SQL-запросы, комментарии и выводы, разделенные по блокам.

Источник данных: Курс "Аналитик данных", модуль SQL.
### Инструмент
PostgreSQL: оконные функции (DENSE_RANK(), LEAD(), SUM() OVER (), AVG() OVER ()), CTE и подзапросы, JOIN, CASE, агрегатные функции, FILTER (WHERE...).
### Структура данных
Данные хранятся в реляционной базе данных

1. Таблица customers
- created_at — дата и время регистрации клиента в системе.
- customer_city — город, в котором проживает клиент.
- customer_id — уникальный идентификатор клиента.
- customer_zip_code — почтовый индекс места проживания клиента.
2. Таблица order_items
- order_id — уникальный идентификатор заказа, к которому относится товарная позиция.
- order_item_id — уникальный идентификатор позиции внутри заказа (например, порядковый номер товара в заказе).
- price — цена товара в данной позиции заказа.
- product_id — уникальный идентификатор товара, связанный с таблицей products.
3. Таблица orders
- customer_id — идентификатор клиента, оформившего заказ (связь с таблицей customers).
- order_approved_timestamp — дата и время подтверждения заказа (например, после проверки платежа).
- order_created_timestamp — дата и время создания заказа.
- order_delivered_carrier_timestamp — дата и время передачи заказа логистической компании.
- order_delivered_customer_date — дата и время фактической доставки заказа клиенту.
- order_estimated_delivery_date — ожидаемая дата доставки, указанная при оформлении.
- order_id — уникальный идентификатор заказа.
- order_purchase_timestamp — дата и время оплаты заказа клиентом.
- order_status — текущий статус заказа (например, «отменён», «доставлен», «в обработке»).
4. Таблица products
- product_brand — бренд товара (например, «Samsung», «Nike»).
- product_category_name — категория товара (например, «электроника», «одежда»).
- product_height_cm — высота товара в сантиметрах.
- product_id — уникальный идентификатор товара.
- product_length_cm — длина товара в сантиметрах.
- product_weight_g — вес товара в граммах.
- product_width_cm — ширина товара в сантиметрах.
5. Таблица customer_actions
- customer_id — идентификатор клиента
- event_timestamp — дата и время события
- event_type — тип события
- order_id — идентификатор заказа
- product_id — идентификатор товара

### Содержание проекта
1. Общие метрики бизнеса
- выручка по дням и скользящее среднее выручки за 3 дня
- количество новых регистраций по дням + накопительное количество пользователей (рост клиентской базы)
- DAU, WAU, месячная выручка, MAU, платящие пользователи, ARPPU
- retention: недельный и месячный
2. Воронка конверсии:
- Общая пользовательская воронка: Регистрация → Page View → Add to Cart → Purchase
- Воронка по товарам (поиск товаров с проблемной конверсией)
3. Товары, бренды и категории товаров
- Пример ad hoc ситуации: цена со скидкой 5% или с промокодом −100 ₽ (гипотетическая оценка)
- Коэффициент ценовой вариации (топ-10 нестабильных товаров)
- Выявление премиальных брендов: со средней ценой ≥ средней по магазину в 1,2 раза
- Топ-3 самых дорогих товара в каждой категории
- Премиальные и бюджетные товары внутри категории и бренда
- Топ-10 брендов по выручке + топ-10 их категорий по выручке
